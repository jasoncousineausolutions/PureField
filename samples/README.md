# Samples

Public PDFs with their Adobe Reader prints, so the tests and tools run without
finding your own forms. Each folder's `acrobat/` holds the same files opened in
Adobe Acrobat Reader on Windows and printed with "Microsoft Print to PDF" on
Letter paper: the target output. A4 forms were scaled to fit, so compare them
scaled.

- `xfa/`: 25 XFA forms, static and dynamic, from governments, Adobe, PDFium,
  iText and the pdf.js corpus. `reference-notes.json` flags Reader prints that
  are not a fair target (`tools/score.py` and `tools/bench.py` honour it).
- `nonxfa/`: 8 ordinary PDFs: AES-256 encryption, layers, AcroForm
  JavaScript, annotations without appearances, fonts the file does not
  embed, /UserUnit and a blend mode. `sources.json` gives each one's source and,
  for the encrypted ones, the password.
- `reader-tests/`: PDFs generated by `tools/reader-tests.mjs` to see what
  Reader draws itself (barcodes, stamps and clouds, field appearances, CJK
  widths).

Score Purefield against the prints:

    node tools/flatten-samples.mjs --in samples/xfa --out out/xfa
    python3 tools/score.py out/xfa --ref samples/xfa/acrobat

For a larger corpus, point `tools/bench/run.sh` at any folder of PDFs with
Reader prints in an `acrobat/` subfolder.
